# 그날의 류 · 팀 지식 저장소

**LLM으로 사용하기:** 이 폴더를 Codex에서 열고 `$teoo-wiki`를 호출한다. [위키 스킬 사용법](05-협업/위키%20스킬%20사용법.md)에 설치·검색·조사 반영·PR 제출 예시가 있다.

원격: [stwpst10-collab/teoo](https://github.com/stwpst10-collab/teoo). 로컬 origin 연결 완료. 현재 공개·빈 저장소이며 쓰기 인증과 업로드 공개 범위 확인 전이라 자료는 아직 업로드하지 않았다. 아래 미연결 설명은 이 연결 상태로 갱신한다.

사용자 소유 GitHub 저장소 하나의 `main`이 팀의 통합 기준이다. 팀원은 같은 저장소의 질문별 작업 브랜치에서 조사하고 PR로 제안한다. 통합된 자료를 다시 동기화한 뒤 다음 조사를 시작한다. 이 폴더 자체를 Obsidian vault로 열면 된다.

**[PR 현황판 열기](05-협업/PR-현황.md)** — 들어온 요청·검토 기록·마지막 조회 시각. 원격 미연결 상태에서는 조회 전이라고 표시한다.

## 첫 참여

화면에서 제출하는 순서는 [팀원 PR 제출 안내](05-협업/팀원%20PR%20제출%20안내.md)를 따른다.

1. [CONTRIBUTING](CONTRIBUTING.md)을 읽고 사용자 저장소 접근 권한을 받아 내 PC에 내려받는다.
2. 최신 `main`에서 질문별 브랜치를 만든다.
3. [리서치 양식](00-운영/양식/리서치.md)을 복사하고 [파일명 규칙](00-운영/파일명과-메타데이터.md)에 맞춰 저장한다.
4. `python tools/validate.py`를 실행하고 PR을 제출한다.

팀 판단의 운영 방법은 [공동 브레인 운영안](00-운영/공동-브레인.md), AI가 지켜야 할 규칙은 [AGENTS.md](AGENTS.md)에 있다.

로컬 구조와 검사기는 준비됐다. 원격 저장소·팀원 권한·보호 규칙·상시 자동 동기화는 아직 설정되지 않았다. Git 첫 커밋도 아직 없으므로 현재 파일을 저장한 것만으로 Git 이력이 쌓인 상태는 아니다. 기존 자료 이관 기록은 [이관검증](00-운영/이관검증-20261029.json)에 있다.
