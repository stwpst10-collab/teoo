## 폴더

| 폴더 | 역할 |
|---|---|
| `00-운영` | 공용 규칙: 보고서 워드 작업 기준, 설문 설계 기준, 리서치 운영, 양식 |
| `05-협업` | 팀원 PR·자료 전달 방법 |
| `10-아이템탐색` | 새 아이템 후보 노트(아이디어당 1개), 검토 기준, 후보 비교 |
| `10-아이템탐색/근거` | 후보 검토에 쓴 출처 노트. 원문은 `근거/첨부/` |
| `10-아이템탐색/산출물` | 후보별 장표·컨셉보드 |
| `tools` | 검사기(`validate.py`)·서식 도구(`pitch/style_ref.py`, `pitch/live.py`) |
| `99-보관/그날의 류` | 첫 아이템 전체 보관 |

새 아이템이 정해지면 그 아이템의 지식·리서치·근거·결정 폴더를 위에 새로 만든다.
