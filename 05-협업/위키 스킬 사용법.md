# 위키 스킬 사용법

`$teoo-wiki`는 그날의 류 온톨로지를 읽고 조사·지식·산출물 반영과 PR 제출을 돕는 스킬이다. 화면 표시 이름은 **teoo 사내벤처 위키**다. 데이터를 별도 서비스에 복제하지 않고 이 저장소의 한글 노트·근거·결정·모델을 직접 사용한다.

## 처음 사용하는 팀원

스킬이 GitHub에 반영된 뒤 다음 순서로 사용한다. 현재 원격 배포 상태는 [팀원 PR 제출 안내](팀원%20PR%20제출%20안내.md)의 연결 상태를 확인한다.

1. Git이 설치된 PC에서 저장소를 내려받는다.

   ```sh
   git clone https://github.com/stwpst10-collab/teoo.git
   cd teoo
   ```

2. Codex에서 내려받은 **teoo 폴더를 작업 폴더로 열고 새 대화**를 시작한다. 저장소의 `.agents/skills/teoo-wiki/SKILL.md`가 프로젝트 스킬이다. 공식 Codex의 저장소 스킬 경로를 사용한다.
3. 입력창에서 `$teoo-wiki`를 선택하거나 다음 요청을 입력한다.

   ```text
   $teoo-wiki 오비라의 커뮤니티 수요 검증 근거와 아직 모르는 점을 알려줘.
   ```

스킬이 목록에 나타나지 않으면 올바른 teoo 폴더를 열었는지와 스킬 파일이 있는지 확인하고 새 대화를 연다. 프로젝트 스킬과 같은 이름을 전역에도 중복 설치할 필요는 없다.

## 이렇게 요청한다

| 하고 싶은 일 | 요청 예시 |
|---|---|
| 근거 찾기 | `$teoo-wiki 현재 수동 목업 결정과 근거를 찾아줘.` |
| 경쟁사 이해 | `$teoo-wiki 오비라 사례에서 확인 사실과 업체 주장을 구분해줘.` |
| 조사 반영 | `$teoo-wiki 이 조사 자료를 기존 근거와 비교해서 위키에 반영해줘.` |
| 산출물 찾기 | `$teoo-wiki 최신 시뮬레이션 모델링과 프로토타입 시안을 찾아줘.` |
| 팀 제출 | `$teoo-wiki 내가 변경한 조사 자료를 검증하고 teoo의 main으로 PR을 제출해줘.` |
| 관리자 검토 | `$teoo-wiki 새 PR을 읽고 채택·보류할 근거를 검토 기록에 적어줘.` |

검색 요청은 읽기만 한다. 로컬 반영 요청만으로 PR을 보내거나 병합하지 않는다. PR 제출을 요청하면 대상·권한·변경 파일을 확인한 뒤 작업 브랜치에서 제출한다. 병합은 별도 요청이다.

## 권한과 준비물

- 공개 자료 내려받기·읽기는 GitHub 로그인 없이 가능하다. 검색 도우미는 Python 3.10 이상과 Git을 사용하며 추가 Python 패키지가 없다.
- 같은 저장소에 브랜치를 올리고 PR을 생성하려면 팀원 본인의 GitHub 인증과 teoo 쓰기 권한이 필요하다. 관리자가 팀원 GitHub 아이디를 초대한다.
- PR 도구는 사용 가능한 GitHub 연결 또는 GitHub CLI를 사용한다. 인증이 없으면 로컬 결과까지 준비하고 미제출 상태를 알린다.
- 소유자 계정 비밀번호나 토큰을 팀에 공유하지 않는다. 이 스킬은 접근 권한을 자동으로 부여하지 않는다.
- 다른 SKILL.md 지원 LLM에서도 스킬 본문을 읽어 사용할 수 있지만, 자동 발견 경로와 호출 문법은 해당 도구에 맞게 설치해야 한다. 모든 LLM에서 같은 호출 문법이 된다고 가정하지 않는다.

## 다른 폴더에서도 사용할 때

Codex의 skill-installer가 제공되는 환경에서는 다음처럼 요청해 사용자 스킬로 설치할 수 있다. 저장소에서 쓰는 경우에는 별도 전역 설치가 필요 없다.

```text
$skill-installer stwpst10-collab/teoo 저장소의 .agents/skills/teoo-wiki 스킬을 설치해줘.
```

전역 설치한 스킬은 온톨로지 전체를 포함하지 않는다. 처음 호출할 때 기존 체크아웃을 찾거나 사용자 PC에 teoo를 내려받는다. 기존 작업 폴더를 덮어쓰지 않는다.

## 갱신과 검증

최신 자료를 받을 때는 미반영 작업을 보존하고 main을 fast-forward로 갱신한다. 다른 사람의 변경을 강제 초기화하지 않는다. 자료 변경 후 `python tools/validate.py`를 실행한다. 검색·읽기·저장소 확인 도우미는 네트워크 업로드나 파일 수정을 하지 않는다.
