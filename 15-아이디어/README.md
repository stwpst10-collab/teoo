# 15-아이디어

사업·제품 아이디어와 채택 상태를 관리한다. 아이디어 하나당 노트 하나를 둔다.

| status | 뜻 |
|---|---|
| 아이디어 | 제안만 있음. 팀 결정 전 |
| 검증 중 | 50-검증에 질문·실험이 연결됨 |
| 채택 | 사용자·팀이 채택. 40-결정에 결정 기록이 있어야 함 |
| 보류 / 폐기 | 이유와 날짜를 남김. 노트는 지우지 않음 |

흐름: 15-아이디어 → 50-검증 → 40-결정 → 10-지식. 10-지식에는 결정으로 확정된 내용만 옮긴다.

각 노트에는 출처(30-근거), 기존 결정·가정과의 차이, 확인 필요 항목을 함께 적는다. 보고서·재무에 쓸 후보는 `## 보고서 반영 포인트`, `## 재무 입력값 후보`에 모으고, 해당 파일 수정은 보고서·재무 하위가 한다.
