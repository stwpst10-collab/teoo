# teoo 팀 위키 (Claude 웹앱)

대상은 GitHub `stwpst10-collab/teoo` 저장소의 자료다. **웹앱은 사용자 PC 폴더나 GitHub 저장소에 자동으로 접근하지 못한다고 가정한다.** 사용자가 이 대화나 프로젝트에 올린 파일만 근거로 쓴다.

작업 전에 이 스킬 폴더의 `references/rules.md`(공통 운영 규칙)를 읽는다. 자료 위치는 `references/workflows.md`의 표를 따른다. 규칙과 이 파일이 다르면 rules.md가 우선하고, 업로드한 스냅샷 안의 `AGENTS.md`가 그보다 최신이면 그것을 따른다.

## 1. 자료 확인

코드 실행 환경에서 업로드된 파일을 확인한다.

1. **teoo 스냅샷 ZIP**(`teoo 자료 스냅샷 날짜 커밋.zip`)이 있으면 작업 폴더에 풀고, 이 스킬 폴더의 도우미로 기준을 확인한다.

   ```sh
   python <스킬 폴더>/scripts/wiki.py --repo <압축 푼 폴더>/teoo status
   ```

   `source: snapshot`, `commit`, `exported`가 나오면 이 값을 답변의 기준 시점으로 적는다.
2. **GitHub에서 받은 일반 ZIP·개별 Markdown·프로젝트 지식 파일**만 있으면 파일을 직접 읽는다. 이때 기준 커밋은 "미확인"으로 적고, 폴더 경로가 없으면 파일명만 근거로 표시한다.
3. **아무 자료도 없으면** 답을 지어내지 않는다. 아래 "자료 연결 방법"을 안내하고 멈춘다.

`git clone`, GitHub API 호출, 토큰 입력을 시도하거나 요청하지 않는다. 네트워크가 열려 있어 보여도 저장소 접근을 가정하지 않는다.

## 2. 조회

```sh
python <스킬 폴더>/scripts/wiki.py --repo <teoo 폴더> search "오비라"
python <스킬 폴더>/scripts/wiki.py --repo <teoo 폴더> read "20-리서치/오비라 커뮤니티 수요 검증.md"
```

- 문장 전체가 아니라 핵심어로 검색한다(예: "최신 시뮬레이션 모델링 찾아줘" → `시뮬레이션`, 그다음 `80-산출물/README.md` 읽기).
- 개념·관계는 `10-지식` 노트의 링크와 `40-결정`·`50-검증/리서치 질문 목록.md`를 따라간다.
- 엑셀(`.xlsx`)·이미지 산출물은 스냅샷에 포함돼 있으면 코드 실행으로 열어 볼 수 있다. 열지 않았다면 내용을 단정하지 않는다.
- 조회 요청에서는 어떤 파일도 만들거나 고치지 않는다. 답변 형식은 rules.md를 따른다.

## 3. 새 조사 반영

웹앱에서는 저장소에 직접 쓸 수 없다. 반영 요청이면:

1. 기존 주제·질문을 먼저 검색한다.
2. `00-운영/양식/리서치.md` 양식으로 한국어 파일명의 새 리서치 파일을 만든다. `review: pending`, 출처·날짜·사실/회사 주장/추론/미확인 구분을 지킨다.
3. 기존 결정과 다른 의견은 덮어쓰지 않고 제안 절에 적는다.
4. 스냅샷 안에 `tools/validate.py`가 있으면 변경 파일을 스냅샷 복사본의 같은 경로에 넣고 `python tools/validate.py --root <복사본>`을 실행한다.
5. 결과 파일을 저장소 상대 경로 그대로 다운로드할 수 있게 제공하고, `.github/pull_request_template.md` 형식의 PR 본문 초안을 함께 준다.

## 4. 제출 요청

웹앱 스킬은 push·PR을 만들 수 없다. "제출해줘"라는 요청에는 준비한 파일과 PR 본문 초안을 주고, 다음 중 하나로 제출하라고 안내한다. **PR을 만들었다고 말하지 않는다.**

- Claude Code에서 teoo 폴더를 열고 `/teoo-wiki 이 파일들을 검증하고 PR로 제출해줘`
- GitHub 웹에서 `research/아이디/주제` 브랜치를 만들어 파일을 올리고 `main`으로 PR 생성(05-협업/팀원 PR 제출 안내.md)

## 자료 연결 방법 (사용자 안내용)

- 권장: Git이 있는 팀원이 teoo 폴더에서 `python tools/export_snapshot.py`를 실행해 만든 `teoo 자료 스냅샷 ….zip`을 대화나 프로젝트에 올린다. 커밋된 파일만 들어가고 인증 정보는 들어가지 않는다.
- 대안: 저장소 접근 권한이 있으면 GitHub의 **Code → Download ZIP** 파일을 올린다(기준 커밋 미확인).
- 대화 첨부는 그 대화에만, 프로젝트 지식은 그 프로젝트에만 적용된다. 스냅샷은 만든 시점의 자료이므로 오래되면 새로 만들어 올린다.
- 회사 자료를 claude.ai에 올리는 것은 외부 서비스 업로드다. 공유 범위를 확인한다.
