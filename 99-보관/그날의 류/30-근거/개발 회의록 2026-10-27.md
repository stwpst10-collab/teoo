# 황토볼 귀지압 시연제품 개발 회의록

## 1. 핵심 결론

- 시연제품은 전자기기가 아닌 수동 방식으로 제작한다.
- 완성형 제품 개발보다 착용 형태와 지압 압박감을 보여주는 목업 제작을 우선한다.
- 개발에 앞서 양사 간 역할 및 특허·기술 소유권, OEM·수출 협력 관계를 명확히 한다.
- 시연제품 제작에 그치지 않고, 실제 수익성이 있는 사업인지 원가와 사업 구조를 검토한다.

## 2. 주요 논의 사항

### ① 시연제품 개발 방향

- 발목보호대와 유사한 형태로 착용 구조 검토
- 황토볼 또는 원추형 압박부를 부착해 지압감 구현
- 우선 3개 혈자리의 위치와 압박감을 시연할 수 있도록 제작
- 3D 프린팅을 활용한 압박부 제작 검토
- 펌프·배터리·EMS·온열 등 전자식 기능은 후속 개발 단계에서 검토

핵심: 양산형 제품이 아닌 PT 및 사용성 평가용 시연제품을 우선 제작한다.

### ② 프로토타입 구현 범위

- 단순히 안마볼이 피부를 누르는 수준으로 충분한지 평가 기준 확정 필요
- 넓은 부위를 압박할지, 특정 혈자리를 집중적으로 누를지 검토

### ③ 기술 구현 및 원가 이슈

| 항목      | 주요 이슈 및 검토 사항                                                                                      |
| ------- | -------------------------------------------------------------------------------------------------- |
| 공기압     | 펌프와 배터리가 필요해 제품 크기 및 원가 증가. 착용 방식과 제품 크기를 고려한 구조 설계 필요                                             |
| 배터리     | 목표 사용 시간 및 1회 충전 시 사용 횟수를 고려한 배터리 사양 제안 필요                                                         |
| 사용성     | 착용·탈착 방법 및 사용 편의성을 고려한 기기 설계 필요                                                                    |
| EMS/FES | 지압과 작동 원리가 다르므로 적용 필요성 검토                                                                          |
| 온열      | 전력 소모가 커 배터리 사용 시간에 부담. 적용 시 전력 및 발열 안전성 검토                                                        |
| 생산·소싱   | ① 베트남에서 부품 소싱 후 중국에서 생산 ② 베트남·중국에서 부품 소싱 후 한국에서 조립(Made in Korea 소구 가능 여부 검토). 제조국별 생산 단가 차이 비교 필요 |
| 원가      | 회의 중 약 4만\~4만 5천 원 수준 언급. 만 세트 발주 기준으로 세부 원가 확인 필요                                                 |
| 인증      | KC 인증 비용 약 600만 원 예상. 적용 인증 항목 및 실제 비용 확인 필요                                                       |

### KC 인증 관련 업체 설명

- 전자기기 및 디바이스에 필요한 인증으로 언급됨.
- 의료기기와 달리 웰니스 디바이스는 제품 인증을 한 번 받으면 되는 것으로 업체에서 설명함.
- 제조사는 1년 단위로 점검받는다고 업체에서 언급함.
- 업체 설명을 기준으로 KC 인증은 사업 추진 시 주요 우려 사항까지는 아닌 것으로 판단됨. 단, 실제 적용 인증과 사후관리 요건은 제품 사양 및 관련 규정 확인 필요.

### 주요 확인 사항

- 그날의료기: 배터리 사양 제안 및 기기 설계 시 사용자 사용성 검토
- 만 세트 발주 기준 제조원가 및 부대비용 확인
- 베트남·중국·한국 생산 방식별 단가 및 원산지 표시 요건 비교
- KC 인증 적용 항목, 예상 비용 및 사후관리 요건 확인
