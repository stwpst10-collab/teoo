- 숫자 카드: PMS 유병 여성(국내 추정) 374만 명(가임기 여성 약 1,100만 × 국내 PMS 유병률 34%) / 한 해 PMS로 진료받은 환자 약 8천 명(건강보험심사평가원 2012) / 경구피임약 복용률 2~3% / 3년차 순매출(VAT 제외) 139~180억(영업이익 41~57억, 소모품 비중 47~59%)

- 하단: 제품 효능 표현은 하지 않음(체감·루틴), 의료기기 인증은 로드맵 옵션.

### 02 IR 01 문제 — "거의 모두가 겪지만, 거의 아무도 관리받지 않는다"

- 막대: 월경 전 증상 경험 99% · 일상생활에 영향 79% · PMS 유병률(한국) 34% · PMDD 3%(한국 가임기 여성 1,000명 온라인 조사, 성균관대 의대 최두석 교수팀, 2008).
- 공백: PMS 유병 추정 374만 vs 연간 진료 환자 8천 → "병원 문턱을 넘는 건 약 0.2%"(진료 환자: 심평원 2012, 머니투데이 2015 보도, 연도 차이 있는 근사).
- 증상: 정서(짜증·불안·우울·감정 기복), 신체(부종·유방통·복부 팽만·두통), 행동(피로·수면·집중 저하·식욕).
- 지금의 선택지: 참기 / 진통제(PMS 정서·부종엔 한계) / 피임약·처방(호르몬 부담) / 영양제(감마리놀렌산 등, 체감 늦음).
- PMS ≠ 생리통: 생리통(D-day~D+3)은 진통제·온열팩·쑥뜸으로 붐빔, PMS(D-7~D-1)는 이름 붙은 상품·카테고리가 없음 → "우리는 생리 전을 판다".

### 03 IR 02 왜 지금 — "약은 싫고, 알림은 이미 온다 — 빈 칸은 '그다음에 살 것'"

- ① 호르몬 회피: 경구피임약 복용률 2~3%, 안 먹어 본 여성의 80% 이상이 "부작용 염려"(대한산부인과의사회 피임생리연구회, 의약일보·코메디닷컴 보도).
- ② 알림은 이미 있다: 올리브영 W케어가 산부인과 전문의와 만든 주기 예측으로 PMS·배란·가임기 알림을 보냄(CJ뉴스룸·청년일보).
- ③ 유통이 키운다: W케어 상품 수 1만 8천여 개, 2022년 대비 약 5배. 입는 생리대 +41% · 여성청결제 +67%(바이라인네트워크 2025·CJ뉴스룸).
- W케어 카테고리 W밸런스(생리대·라이너)·W클렌징(Y존)·W러브(러브 에티켓)·W웨어(컴포트웨어) + 빈 칸 "W프리(가칭) — PMS · 생리 전 7일".
- 하단: 펨테크 세계 시장 2025 464.7억 달러 → 2026 558.8억 달러(+20.2%, The Business Research Company).

### 04 IR 03 시장 규모 — "국내 PMS 관리 시장 약 2,928억 원 — 첫 타깃 1,573억"

- TAM 2,928억(374만 명) / SAM 2030 여성 1,573억(201만 명) / SOM 3년차 139~180억(SAM의 9~11%).
- 계산(VAT 제외): 가임기 여성(15~49세) 약 1,100만(2022 1,135만, 매년 감소 → 보수적으로 내림) × PMS 유병률 34% = 374만 / 2030 여성 약 590만(20·30대 24.2% × 5,112만 × 여성 48% 가정) × 34% = 201만 / 1인 연 지출 7.8만 원(소모품 6.8만 + 기기 3.2만 ÷ 3년).
- 읽는 법: TAM = 지금은 "참기"에 쓰이는 시장, SAM = 올리브영 핵심 고객층과 겹치는 2030, SOM = PB 06 재무 모델과 같은 숫자, 해외: 세계 PMS 유병 9.56억 명(GBD 2019).
- 하단 출처: 인구 뉴스1(통계청 주민등록 분석), 행안부 2025 주민등록 연령 비중, 유병률 최두석 교수팀 2008.

### 05 IR 04 타깃 고객 — "'호르몬제는 싫은데, 그냥 참기도 싫은' 2030 여성"

- 언제: D-7(W케어 알림) ~ D-1이 "우리 시간". D-3 키트 재구매. D~D+2는 "생리통 구간 — 기존 상품과 경쟁하지 않음". PMS 루틴: 알림 → 매일 저녁 10~15분 꾹 · 알 패치로 자리 표시 · 꾹 밤.
- 핵심 고객(1차): 25~34세 직장인·대학원생 여성, PMS 중등도(매달 3~7일 짜증·부종·피로로 일정 조정), 피임약·처방 원치 않음, 올리브영 앱 사용·W케어 주기 입력, "루틴템"에 월 1~2만 원.
- 그녀가 지금 하는 것: 달력 앱 기록만, D-day에 진통제, "그 기간"엔 약속 줄임, 영양제를 샀다가 끊음 → 끼어드는 지점: 알림이 온 D-7.
- 일부러 뺀 고객: PMDD(약 3%, 진료가 맞음, 앱에서 병원 안내) · 심한 생리통·자궁 질환 의심(진료 우선) · 임산부(사용 금지 표기) · 10대(2차 확장, 보호자 구매).

### 06 IR 05 해법 — "PMS를 '참는 기간'에서 '관리하는 루틴'으로"

- 흐름: ① 알림 · 올리브영 W케어 "PMS 시작 D-7"(주기 예측 이미 운영 중, 앱 개발비 0원) → ② 루틴 키트 · 우리 제품 "꾹 + 알 패치 + 꾹 밤"(혈자리(삼음교·합곡) 한 점 지압 기기, 자리 표시 패치, 바르는 밤, 비발열 인서트, 호르몬 0 · 약 0 · 매일 10~15분) → ③ 매달 재구매 "그날 키트 22,900"(D-3 알림 → 장바구니, 활성 1인 연 7.4만 원) → 다음 주기 알림으로 순환.
- 왜 혈자리 지압인가: 삼음교(SP6) 지압은 생리 관련 증상 연구가 가장 많은 비약물 방법 / 연구 프로토콜 엄지 1.2→3.5kg · 6초 누르고 2초 쉬기 · 20~30분 / 꾹 최대 압력 ≈ 1.8kg/cm² — 엄지 지압과 같은 범위(Kashefi 외 RJMS 2009 · Charandabi 외 2011, 연구는 주로 생리통 대상 — PMS 체감은 자체 사용자 연구로 검증(IR 08)).
- 왜 "루틴"인가: PMS는 매달 7일씩 30~40년 반복 / 표시·향·기분이 매달 소모 / 옵션은 강요 없이 "꾹만으로" 작동.
- 말하지 않는 것: "PMS 치료·완화" 효능 표현 없음(공산품), 카피 "생리 전 7일, 내 루틴"·"호르몬 없는 루틴", 효능 표현은 의료기기 인증 후(로드맵 옵션).

### 07 IR 05-B 왜 꾹인가 — "효과가 난 건 '전문가가 누를 때'. 꾹은 그 손을 매일 재현하는 첫 PMS 디바이스"

- 셀프 지압이 흔들리는 4가지 → 꾹의 답: 자리(어림짐작 → 황토 알 패치로 고정) / 압력(손이 지침 → 최대 약 1.8kg/cm² 일정, 20N 스프링 상한) / 리듬·시간(6초·2초 × 20~30분 세기 어려움 → PMS 모드, 15분 자동) / 매일 지속(두 손이 묶여 포기 → 끈으로 핸즈프리 + W케어 D-7 알림). 출처: Abaraogu 외 2016 메타분석(6개 연구 461명) — 훈련된 사람이 시행한 SP6 지압은 직후 통증 감소가 유의, 셀프는 여러 주기 필요, 연구 질 낮음, 대상은 주로 생리통.
- 개념도: 혼자 엄지는 점점 약해지고 리듬이 무너짐 vs 꾹 PMS 모드 6초 꾹·2초 쉼, 끝까지 같은 압력(실제 곡선은 시제품 압력 센서 실측으로 교체 예정, IR 08 · 0~3개월).
- PMS 관점 상품 비교(정확한 한 점/일정한 압력/연구 리듬/핸즈프리/주기 연동/가격): 엄지 셀프 지압 0원 / 지압 밴드·집게(Sea-Band·Aculief) 1~3만 / EMS·쑥뜸 미니스팟(바르너) 4.9~9.7만 / 공기압 마사지기 10만+ / 꾹 2.99만(모두 ○). "5개 항목을 모두 채우는 상품은 찾지 못함(PB 07 경쟁 조사) · 바르너 외 가격은 대략치 · 모터+캠 한 점 지압은 특허 선례만 있고 대중 상품 없음".
- PMS 전용으로 설계한 것: PMS 모드(버튼 길게, 펌웨어라 원가 +0원) / 연구에 가장 많이 쓰인 자리부터 — 삼음교(SP6, 9편) · 태충(LR3, 4편)을 키트 지도·알 패치 위치로 / D-7 → D-1 루틴 / 먼저 만든 쪽이 표준이 됨. 자리별 연구 수: Effect of Acupressure on Primary Dysmenorrhea 리뷰(28편).

### 08 IR 05-C 넓은 면 vs 정확한 한 점 — "꾹은 '짚어 주는' 기기"

- 원리: 같은 20N ÷ 손바닥 크기 약 50cm² ≈ 0.04kg/cm² vs 20N ÷ 약 1.1cm²(꾹 ø12mm 팁) ≈ 1.8kg/cm². "같은 힘이면 한 점이 약 45배 높은 압력", 삼음교 연구 엄지 최대 압력(3.53kg ÷ 엄지 약 2cm²)과 같은 범위, 손목 통증 역치 평균(약 5kg/cm²)보다 낮아 안전 여유.
- 연구는 "한 점 · 충분한 압력": 2013 메타분석(Acupuncture or Acupressure at SP6 for Primary Dysmenorrhea) — 삼음교 지압 그룹이 대조군(휴식·가벼운 터치·비혈자리)보다 통증 점수가 유의하게 낮음 / 단서: 같은 메타분석의 침 연구에선 자리 차이 불분명 · 연구 질 낮음 → 출시 전 자체 사용자 연구로 체감 확인. 대상은 생리통.
- 고객 관점(넓은 면 마사지기 vs 꾹, 검증 방법): 제대로 하고 있나("확신" 점수) / 언제·어디서(2주기 사용 일지) / 내 몸 이해(4주 뒤 자리 스스로 찾기 정확도) / 강도 조절(넓은 면 전체 vs "한 점만 5단계", 단계별 선호 분포) / 가격·휴대(10만 원대 이상 vs 29,900원·파우치, 매장 테스터 → 구매 전환율). "고객 관점은 가설 — IR 08 사용자 연구(PMS 여성 50명 × 2주기)에서 측정".

### 09 IR 05-D 선물과 패키지 — "'그날 힘들다며' — 위로를 선물하는 첫 PMS 기프트"

- 패키지 시안 "그날 선물 세트": 꾹·끈·꾹 밤·알 패치, 손글씨 카드, 라벨 "그날, 내가 대신 꾹 — QR · 내 자리 찾기 영상".
- 왜 선물: 말하기 어려운 걸 대신 말해 줌 / 3만 9천 원 가격대(가정) / 열면 바로 루틴 / 시즌(여성의 날·화이트데이·생일·연말·입사·졸업).
- 올리브영 선물하기: 2020년 도입 이후 연평균 176% 성장, 40대 이상 주문 금액 첫해 대비 18배, 모바일 선물 매장 픽업(CJ뉴스룸).
- 선물·묶음 SKU(판매가 / VAT 제외 / 원가 / 원가율 / 개당 이익): 그날 선물 세트 39,900 / 36,273 / 13,290 / 37% / 22,983(꾹 1·끈 L·꾹 밤 10g·알 패치 30·체험 인서트 2·선물 박스·카드) · 둘이 쓰는 세트 59,900 / 54,455 / 21,000 / 39% / 33,455 · 그날 키트 기프트 24,900 / 22,636 / 4,940 / 22% / 17,696. 원가 = 부품 합 × 1.05, 선물 박스 1,200원 가정, 개별 구매 합 49,700 → 39,900.
- 선물 → 리필 고객: 카드 QR → 내 자리 찾기 영상 + W케어 주기 등록 → 첫 D-7 알림 = 첫 키트 구매 시점. "선물 SKU는 IR 07·PB 06 매출 모델에 넣지 않음 = 모델 밖 업사이드".

### 10 IR 06 경쟁 지도 — "약이 아니면서 생리 '전'에 몸으로 하는 루틴 — 그 칸에 제품이 없다"

- 축: 가로 약물·호르몬 ↔ 비약물, 세로 생리 전·루틴(D-7~) ↔ 아플 때·사후(D-day~). 오른쪽 위: 꾹·그날 루틴(★), 영양제(체감 늦음), 주기 앱(기록만). 왼쪽 위: 피임약·처방, 한방 탕약. 아래: 진통제, 온열팩·쑥뜸·EMS(바르너).
- 각 대안의 한계: 피임약·처방(호르몬 부담·복용률 2~3%) / 진통제(통증만·정서·부종 미해결·사후) / 영양제(체감까지 수개월·이탈 높음) / 주기 앱(기록·알림뿐) / 바르너 등 온열·EMS(생리통·근육 중심·기기 단품).
- 우리가 지키는 해자: 올리브영 PB 진열 + W케어 알림 연동(유통 독점력) / 퍽 걸쇠 규격·주기별 키트 구성(디자인·실용신안) / 사용자 주기·루틴 데이터 → 키트 개인화. "지압 원리 자체는 특허 독점 불가(Woodside 모터+캠 특허 선례)".

### 11 IR 07 비즈니스 모델 한 장 — "1년차 BEP · 3년차 139~180억 — 매출을 반복해서 만드는 건 소모품 앵커"

- 원가표(판매가 / VAT 제외 / 원가 / 원가율 / 개당 매출총이익): 꾹 스타터(기기) 29,900 / 27,182 / 9,200 / 34% / 17,982 · 꾹 듀얼(기기) 49,900 / 45,364 / 16,480 / 36% / 28,884 · **그날 키트(앵커·주기마다)** 22,900 / 20,818 / 4,480 / 22% / 16,338 · **황토 알 패치 30매(앵커·매일 1장)** 9,900 / 9,000 / 1,580 / 18% / 7,420 · **꾹 밤 10g(앵커)** 9,900 / 9,000 / 1,890 / 21% / 7,110 · 황토쑥 인서트 5매·비발열(옵션) 5,900 / 5,364 / 1,160 / 22% / 4,204 · 쿨 인서트 5매(옵션·여름) 5,900 / 5,364 / 1,730 / 32% / 3,634 · 끈 S·L·어깨 띠(부위 추가) 9,900 / 9,000 / 1,050 / 12% / 7,950. "퍽 1개 6,000원 · 기기 믹스(스타터 75 · 듀얼 25) 평균 원가 11,020원".
- 반복 매출 앵커 — 활성 고객 1명의 1년(VAT 포함): 그날 키트 ×2 45,800 + 황토 알 패치 30매 ×1 9,900 + 꾹 밤 ×1 9,900 + 쿨 인서트 ×1 5,900 + 끈 ×0.3 2,970 = 74,470원. 기기만 산 고객 매출총이익 20,707원 vs 계속 쓰는 고객 3년 181,156원(기기만의 8.7배). 소모품 평균 원가율 21%.

### 12 IR 08 실행 계획 — "검증 → 출시 → 카테고리 소유"

- 출시까지 6~9개월. 첫 12개월 목표는 "PMS 루틴 재구매"를 숫자로 증명.
- 0~3개월 시제품·사용자 연구(works-like 시제품 · 압력 측정, PMS 여성 50명 × 2주기 체감 조사) → 3~9개월 금형·KC·출시(퍽 금형 · KC 전자파 · 임산부 금지 표기, 올리브영 PB 입점 · W케어존) → 9~18개월 PMS 카테고리 만들기(W케어 「생리 전」 탭 제안 · D-7 알림 연동, 그날 키트 정기 구매 · 콘텐츠) → 18개월~ 확장(일본·올영 글로벌몰 · 10대(보호자), 의료기기 인증 검토 → 효능 표현).
- 성공 지표(12개월): 옵션 소모품 90일 재구매율 ≥ 35% / W케어 D-7·D-3 알림 → 키트 전환율 / 사용자 연구: 표준 PMS 척도 자기평가 변화 · 만족도 / 매장 체험 → 스타터 구매 전환.
- 자금 사용처 연 3억(고정비, 억 원, 1·2·3년차): 제품 개발·인증·신규 SKU 0.95/0.5/0.5 · 마케팅·콘텐츠·체험존 1.8/2.0/1.8 · 사용자 연구·해외 0.25/0.3/0.5 · 예비 —/0.2/0.2. 인건비 제외, 재고는 판매 대금으로 회전(초도 3만 대 ≈ 3.3억은 운전자금 · PB 매입 조건 확인 필요).
- 리스크와 대응: 효능 체감(출시 전 사용자 연구로 확인, 강도·리듬 프리셋 확정) / 표현 규제(체감·루틴 카피만, 인증은 로드맵) / 유통 의존(PB로 시작, 2년차 자사몰·해외) / 모방(채널·데이터·키트 구성으로 방어).
