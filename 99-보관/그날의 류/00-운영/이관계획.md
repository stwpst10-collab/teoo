# 공동 지식 저장소 이관 계획

작성일: 2026-10-29. 문서 구조 정리이며 사업 가설·결정을 바꾸지 않는다.

1. 기존 지식 노트·Canvas를 로컬 백업하고 첨부·원본 자료의 SHA-256을 기록한다.
2. 공통 지식, 개별 리서치, 근거, 결정, 검증, 산출물을 분리한다. 공통 노트에는 고정 ID를 부여한다.
3. 위키링크·상대 링크·Canvas 경로를 함께 갱신한다. 기존 원문과 최신 Ovira 자료를 보존한다.
4. Fork·질문별 브랜치·PR·중앙 main 동기화 절차, 리서치 양식, AI 작업 규칙을 추가한다.
5. 개인 설정·임시 파일·브라우저 프로필·의존성을 Git에서 제외한다. 기존 작업자료는 명시된 공유 자료만 허용한다.
6. 읽기 전용 검사기로 링크·ID·메타데이터·충돌 표식을 검사한다. 원본 해시와 새 Git 체크아웃에서도 재검증한다.

검토 분리: 구조 계획은 architect의 읽기 전용 검토를 받았다. 파일 이동은 주 에이전트가 수행하고 검증기는 별도 executor가 작성한다.

보존 범위: 과거 원본·엑셀·생성 결과는 내용 수정 없이 보관한다. 과거 스크립트의 경로는 역사 기록으로 유지하며 재실행하지 않는다.
완료 기준: 원본 바이트 보존, 활성 내부 링크 정상, 제외 파일에 대한 공유 문서 의존 없음, 검증기 테스트 통과. 원격 생성·업로드·팀원 권한·GitHub 보호 규칙은 이 로컬 이관에 포함되지 않는다.
