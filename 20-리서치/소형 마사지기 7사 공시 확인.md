# 소형 마사지기 7사 공시 확인

## 질문과 한 줄 결론

Q19(비교 기업의 매출 구조와 확장 경로): [[경쟁사 7사 분석 텍스트 2026-11-04|경쟁사 7사 분석 텍스트]]의 7개 브랜드(풀리오·휴그랩·슬룸·발란스핏·메디니스·바르너·알로코리아)는 DART에 공시가 있는가, 있으면 매출 규모는 얼마인가?

판단유보. 운영 법인 기준으로 **풀리오(㈜풀리오), 발란스핏(㈜어댑트), 메디니스(㈜미래바이텍) 3사는 DART에 외부감사 감사보고서가 있다(A).** 휴그랩(니즈테크)·슬룸(올릿리테일)·알로코리아는 DART 검색 결과가 없고, 바르너(㈜바이트랩)는 고유번호만 등록되어 있고 공시는 0건이다. 이 4사는 "DART 공시 없음 — 외부감사 대상이 아닌 것으로 추정(미확인)"이다.

풀리오 매출은 공시 기준으로 **2023년 569.8억 → 2024년 1,905.9억 → 2025년 1,348.4억 원**이다. 2023년 값은 2024년 감사보고서의 비교 표시분이며 감사받지 않은 재무제표다. v9 보고서 4장의 "2022년 56억 원"은 공시로 확인되지 않는다.

## 공통 지식에 반영할 제안

- [[시장 수치 대장]] "비교기업 매출·매출 구성"(Q19) 행: 현재 설명(DART 공시, 미입력) → 풀리오 2023~2025, 어댑트 2024~2025(연결, 전사), 미래바이텍 2024~2025 매출을 A등급으로 추가. 이유: 공시 원문 확인.
- [[경쟁사 7사 분석 텍스트 2026-11-04]]의 "풀리오 매출 2022년 56억 → 2023년 570억(보도)": 2023년 값은 공시와 일치(569.8억, 감사 전), 2022년 56억은 미확인으로 표시하도록 제안.
- 해석 제안(판단유보): 공시 3사 모두 광고선전비가 매출의 15~38%로, 소형 마사지기 D2C는 광고 의존 구조다. 풀리오는 광고비를 줄이자 매출이 함께 줄었다. 그날의 류 수익성 가정에 광고비 비중을 별도 변수로 두는 근거가 된다.

## 남은 질문과 다음 행동

- 바이트랩: DART 고유번호만 있고 공시가 없는 이유 확인(2027-04 감사보고서 공시 여부 재조회).
- 슬룸·알로코리아: 자사몰 하단 사업자번호를 브라우저로 직접 확인해 법인명 대조.
- 바르너 150억·바이트랩 600억: 서울경제·바이라인네트워크 원문을 열어 기준(연결/브랜드, 연도) 확인 후 B 확정.
- 풀리오 "2022년 56억" 원 기사 확인 또는 보고서에서 삭제.
- 풀리오 매출 감소 원인(목어깨 V2 리콜 2025.5, 광고 축소)은 미확인. 필요하면 리콜 공고(국가기술표준원·한국소비자원) 원문 확인.

미합의 상태: 팀 검토 전.
