# 환경호르몬·스트레스·생활습관과 PMS·월경통 상관 근거

## 질문과 한 줄 결론

- 질문: 환경호르몬(BPA·프탈레이트·파라벤 등 내분비교란물질), 스트레스, 불규칙한 생활(수면 부족·교대근무·야간근무·식사 불규칙·카페인·흡연·음주·운동 부족)이 PMS/PMDD와 원발성 월경통을 악화시키는가.
- 관련 질문: [[리서치 질문 목록|리서치 질문 목록]] Q18(구조적 수요 내러티브), Q06·Q22(효능 표현 경계).
- 먼저 읽고 재사용한 노트:
  - [[월경 증상 유병률 기준과 대상 인구 보정]] — 국내 심한 월경통 41.6%·심한 PMS 46.1%, "지난 3년" 기준(기존 노트 값 재사용, A).
  - [[온열 생리통 완화 근거의 범위와 질]] — 근거의 질 표기 방식, Armour 2019 자가관리 메타분석(기존 노트 값 재사용).
  - [[생리 지연 고민 규모와 지압 근거·표현 규제]] — 식약처 적발 사례, 의료기기법 제26조 제7항(기존 노트 값 재사용).
- **결론: 판단유보.** 요인별로 결론이 다르다.

| 요인 | 한 줄 판단 | 확신 |
|---|---|---|
| 스트레스 | 월경통·PMS 모두 같은 방향. **전향 연구 2편**에서 "앞 주기 스트레스 → 다음 주기 증상"이 확인됨. 인과에 가장 가까운 요인 | 중간(관찰연구 중 상위) |
| 흡연 | 월경통 메타분석 2편(OR 1.45·1.44), PMS 메타분석 1편(OR 1.56)·코호트 내 환자대조 1편(OR 2.1). 일관됨 | 낮음~중간 |
| 수면 부족·수면의 질 | 같은 방향이 많지만 대부분 단면. **통증이 수면을 깨뜨린다는 실험 근거가 있어 역인과가 큼** | 낮음 |
| 교대·야간근무 | 월경불순은 일관됨. **월경통 통합 OR은 유의하지 않음**(1.51, 0.87~2.62). 30세 이상만 유의 | 낮음 |
| 카페인 | 월경통은 대학생 메타분석에서 OR 2.08. **PMS는 대규모 전향 자료에서 관련 없음**(OR 0.79) | 매우 낮음·상충 |
| 음주 | PMS 메타분석 OR 1.45. **전향 자료(NHS II)에서는 약함·유의하지 않음**(RR 1.19) | 낮음·상충 |
| 운동 부족 | 관찰연구는 약한 상관. 운동 개입 RCT는 월경통 감소(낮은 질) | 낮음 |
| 식사 불규칙(아침 거름) | 학생 메타분석에서만 유의. 원문 효과 크기 미확인 | 매우 낮음 |
| 환경호르몬 | 월경통·PMS를 직접 본 생체지표 연구가 몇 편뿐이고 **결과 없음이 섞임**. 자궁내막증(이차성 월경통 원인)과의 연관이 더 많이 연구됨 | 매우 낮음 |

- 그날의 류에 대한 뜻: "생리 전후 불편은 스트레스·수면·생활 리듬과 함께 움직인다"는 **상관 문장**까지는 근거로 쓸 수 있다. "환경호르몬이 생리통을 만든다", "당사 제품이 스트레스성 생리통을 줄인다" 같은 **인과·효능 문장은 쓸 수 없다.**

## 확인 사실과 해석

### 1. 요인별 근거 표 (해외·국제 중심, 한국은 §3)

- 읽는 법
  - 인과/상관: "상관"은 같은 시점 측정. "시간 순서"는 노출이 결과보다 먼저 측정됨(인과의 필요조건만 충족). "개입"은 무작위 개입 결과(요인 자체가 아니라 반대 방향 행동의 효과).
  - 근거의 질: 저자가 GRADE를 낸 경우만 GRADE로 적었다. 나머지는 GRADE 관행(관찰연구는 '낮음'에서 시작, 비뚤림·비일관성이 있으면 '매우 낮음')을 따른 **당사 판단(D)** 이다.

**2-3. 동물·기전 근거 (C, 원문 미열람)**

- 쥐·돼지 적출 자궁 실험에서 BPA는 자궁근 수축을 **오히려 약하게** 했다는 보고가 다수다(E33, 웹 검색 요약). 원발성 월경통의 기전(프로스타글란딘 과다 → 수축 증가)과 방향이 맞지 않는다.
- 판단: 기전 근거도 "악화"를 지지하지 않는다. 원문 확인 전이라 C다.

- 국내 전국 단위 유병률은 질병관리청 성·생식건강조사가 대표다(기존 노트 값 재사용, [[월경 증상 유병률 기준과 대상 인구 보정]]). 이 조사는 생활습관과의 교차표를 공표하지 않는다.
- 해석: 국내 연구는 **간호사·청소년·대학생 편의 표본**에 몰려 있다. 25~39세 일반 직장 여성(첫 타깃)을 대표하는 연구는 없다.

### 4. 반드시 구분할 것

**4-1. 상관인가 인과인가**

| 요인 | 판단 | 이유 |
|---|---|---|
| 스트레스 | 인과 **가능성 있음**(미확정) | 전향 2편(E10·E11)에서 시간 순서 충족, 용량-반응(PTSD, E17). 무작위 근거 없음 |
| 흡연 | 인과 **가능성 있음**(미확정) | 코호트 내 환자대조(E13)에서 시간 순서·용량-반응. 메타분석 코호트 하위군도 유의(1.35) |
| 수면 | **상관**. 방향 불명 | 대부분 단면. 통증 → 수면 방향의 실험 근거(E21)가 더 단단함 |
| 교대근무 | **상관** | 메타분석 통합 OR이 유의하지 않음. 국내 전향 1편은 대조군 없음 |
| 카페인·음주 | **상관이 상충** | 전향 자료(E15·E16)에서 관련 없음 |
| 운동 | 운동 **개입**은 월경통을 줄였다(낮은 질). "운동 부족이 악화시킨다"는 별개 명제 | 개입 효과 ≠ 위험 요인 |
| 환경호르몬 | **근거 불충분** | 직접 연구 소수, null 포함, 기전도 방향 불일치 |

**4-2. 역인과 가능성**

| 관계 | 역방향 근거 |
|---|---|
| 월경통 → 수면 악화 | 진통제로 통증을 줄이면 수면 효율·REM이 회복(E21, RCT). 월경통군 수면 효율 82.5% vs 86.2%(E22). 국내 중학생 OR 1.26(K15) |
| 월경통 → 우울·불안·불면 | 1년 추적에서 월경통이 이후 우울·PTSD 발생과 관련(E23). 멘델 무작위에서 월경통 → 우울·불안 위험 증가(E24) |
| PMS → 흡연·음주 | 저자들 스스로 "증상을 달래려 흡연·음주가 늘 수 있다"고 씀(E12·E15). 음주는 전향 자료에서 연관이 사라짐 |
| PMS → 스트레스 지각 | 단면 연구는 PMS 시기에 스트레스를 더 크게 느끼는 것과 구분하지 못함. 앞 주기 스트레스를 잰 E10·E11만 이 문제를 줄임 |

**4-3. 교란 요인**

- 나이·초경 나이·출산 경험·경구피임약(월경통을 줄임, E01·E02).
- 체질량지수(저체중이 월경통·PMS와 관련, E03).
- 가족력(OR 2.1~3.8, E03·E05). 유전과 생활환경이 함께 섞인다.
- 우울·불안(스트레스·수면·흡연과 모두 얽힘).
- 직업·사회경제 수준(교대근무자는 간호직 쏠림, E09에서 고용·소득은 결론 불분명).
- 환경호르몬: 노출이 식습관·플라스틱 사용·소득과 같이 움직인다. "회피 행동" 설문은 건강 관심 전반의 대리 지표다(K13·K14).

**4-4. 결과가 없거나 반대인 연구 (포함)**

| 요인 | 연구 | 결과 |
|---|---|---|
| 카페인 → PMS | Purdue-Smithe 2016 (E16) | 관련 없음, 점추정은 오히려 0.79 |
| 음주 → PMS | Bertone-Johnson 2009 (E15) | 관련 없음(RR 1.19, 0.84~1.67) |
| 교대근무 → 월경통 | Chang 2021 (E18) | 통합 OR 유의하지 않음, 30세 미만도 null |
| 흡연 → 원발성 월경통 | Jenabi 2019 (E07) | 보정 모형에서는 유의하지 않음 |
| 수면 시간·타이밍 → PMS·월경통 | Jeong 2023 (K06) | 보정 후 사라짐 |
| 스트레스 → 통증 강도 | Lee 2024 (K07) | 보정 후 관련 없음(증상 빈도·강도와만 관련) |

| 생체리듬(활동기록계) → PMS | Nexha 2024 (E20) | 차이 없음 |

| 타깃 | 스트레스·수면 부족·교대근무와 같이 묶이는 직장 여성이 "증상을 더 자주 말하는 집단"이라는 해석은 가능하다. 다만 국내 근거는 간호사·학생 표본이다. 25~39세 일반 직장 여성은 측정 필요([[타깃 고객 정의]]). |

## 남은 질문과 다음 행동

1. 사전 설문에 "최근 3주기 중 스트레스가 컸던 주기·잠이 부족했던 주기에 증상이 더 컸는가" 문항을 넣는다. 고객 언어를 얻기 위함이며 인과 검증은 아니다. 담당·기한 미합의.
2. KCI·RISS에서 "월경통 스트레스 직장인", "월경전증후군 교대근무"를 직접 검색해 25~39세 일반 직장 여성 표본 연구가 있는지 확인한다.
3. Mitsuhashi 2022·Choi 2020 전문에서 I²와 비유의 요인(음주·카페인·운동)을 확인해 표를 보강한다.
4. 상세페이지·콘텐츠 문안은 광고 심의 경험자 검토 전까지 "정보성 글"과 "제품 문구"를 분리한다.
5. 미합의 상태: 이 노트의 문장 표는 팀 합의 전이다.
