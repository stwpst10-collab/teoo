# 질병관리청 성생식건강조사 2022

- 원문: 송은솔 외, 「한국 여성의 월경·폐경 관리: 2022년 한국 여성의 생애주기별 성‧생식건강조사 결과」, 주간 건강과 질병(PHWR) 16(25):783-800, 2023-06-29 온라인. https://www.phwr.org/journal/view.html?doi=10.56786%2FPHWR.2023.16.25.1
- 발행: 질병관리청. 확인일 2026-10-31(웹 본문 판독)
- 근거 성격: 정부 기관 조사 결과(A). 온라인 조사, 2022-07-18~09-15
- 관련: Q17·Q18·Q27, [[국내 월경 불편 규모와 대처 공백|국내 월경 불편 규모와 대처 공백]]

## 읽어야 할 위치

| 항목 | 값 |
|---|---|
| 표본 | 청소년 13~18세 1,019명, 성인 19~64세 3,533명. 월경 분석 대상 3,098명(청소년 961, 성인 2,137) |
| 심한 증상 기준 | VAS 1~10 중 7점 이상 |
| 심한 월경통 | 청소년 42.6%, 성인 41.6% |
| 심한 월경전 증후군 | 청소년 29.3%, 성인 46.1% |
| 심한 증상 1개 이상인 사람 중 산부인과·비뇨의학과 진료 | 청소년 9.9%(50/503), 성인 28.5%(361/1,266) |
| 대처(심한 증상자, 성인 N=1,266) | 약국 진통제 59.2%, 건강기능식품·민간요법 18.2%, 한의원 4.8%, 아무것도 안 함 23.5% |
| 대처(청소년 N=503) | 약국 진통제 62.4%, 건강기능식품·민간요법 11.1%, 한의원 3.0%, 아무것도 안 함 25.4%(본문 25.5%) |
| 진료 안 받은 이유(성인) | 진통제로 해결 가능 37.2%, 증상이 가벼워서 28.1%, 진료 꺼려짐 14.4% |
| 폐경 이행·폐경 여성의 심한 증상 | 수면 문제 28.0%, 질 건조 27.2%, 관절·근육 불편 23.3%, 신체·정신 피로 21.5% |

대처 응답 항목에 온열·마사지 기기·패치 같은 비약물 셀프케어가 따로 있는지는 본문에서 확인하지 못했다. 학교·직장 지장 수치는 이 문서에 없다.
