### 1-2. 해석

- 세 품목(이사·인테리어·가구 배송) 모두 피해구제 건수 증가 추세임. 이사 2023→2025 +59%, 인테리어 2022→2025 약 2.2배
- 단, **"여러 업체 간 일정 충돌"은 소비자원 분류에 별도 유형으로 없음**. 일정 문제는 다음 항목에 흩어져 간접적으로만 잡힘
  - 인테리어 "계약 불이행"(공사 기간 미준수 포함) 25.2% — 공사 기간 미준수만 따로 뺀 비율은 확인 못 함
  - 가구 "배송 지연·미배송" 26.4%(2025년 63건)
  - 현장 "추가 비용 요구": 청소 20.5%, 소규모 이사 24.9% — 초안의 "이사 당일 50만원 추가 요구"와 같은 유형
- 이사 피해의 중심은 **파손(69.9%)**이지 일정이 아님 → 일정 조율 문제의 정량 근거로는 약함(반대 근거 6장 참고)
- 가구 배송 기사(경향 2026-06-16)는 "2021~2025년 152건"과 "연평균 200건"이 함께 적혀 숫자가 서로 맞지 않음. 다른 매체는 같은 기간 1,052건으로 보도함(검색 결과 요약 기준). 5년 총계는 인용하지 말고 **2025년 239건·유형 비율만 사용** 권장
- 소비자원 보도자료 원문(kca.go.kr)은 직접 열람 못 함 → 보고서 인용 전 원문 확인 필요
- 가구 배송 관련 1372 상담 건수: 확인 못 함
- 피해구제는 "분쟁까지 간 건"만 셈. 실제 불편 규모는 훨씬 클 수 있으나 그 배수는 확인 못 함(당사 추정)

  - 엘리베이터 예약(동당 하루 3가구)·키 불출·잔금 일정이 고정 제약으로 걸림 → 시공 하나 밀리면 연쇄 지연 가능성(당사 추정, 실제 연쇄 지연 사례는 확인 못 함)

### 7-2. ROOMOVE에 뜻하는 것

- 문제 ②는 **전체 이사 고객이 아니라 "시공 + 이사 + 가구"가 한꺼번에 몰리는 고객**에게만 큼 → 첫 고객을 신축 입주자 또는 구축 매수·부분 리모델링 입주자로 좁히는 편이 근거와 맞음(당사 추정)
- 신축 입주 시장에는 이미 박람회·입주 시공 중개 앱·묶음 판매가 있음. 다만 확인한 범위에서 **"순서·날짜를 묶어 관리하고 지연 때 후속 업체를 재조율"하는 서비스는 보이지 않음** — 빈자리 신호이자, 아무도 돈을 내지 않아서 없는 것일 수도 있음(지불 의사 미확인)
- 공식 통계로 "일정 충돌"을 직접 증명하기 어려움 → 보고서에서는 "공식 통계 간접 근거 + 직접 조사"로 구성해야 함

### 7-3. 측정 필요(다음 조사)

- 신축 입주 예정 단지 카페·박람회 현장 관측: 가구당 계약 업체 수, 일정 변경 경험률
- 이사 경험자 설문: 시공 업체 수, 일정 충돌 경험, 조율에 쓴 시간, 조율 대행 지불 의사(가격대)
- 인테리어 감리·PM 대행, 반셀프 코디, 정리수납 서비스 가격 — 이번에 검색 한도로 확인 못 함
- 소비자원 보도자료 원문(kca.go.kr) 대조, 인테리어 "공사 기간 미준수"만의 비율
- 문제 ①(가구·공간 계획) 근거: 오늘의집 커뮤니티·가구 반품 사유 중 "사이즈 안 맞음" 비율
- 초안 커뮤니티 사례(줄눈 5시간 지연 등)의 원문 URL 확인
