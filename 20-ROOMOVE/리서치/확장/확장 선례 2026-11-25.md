# ROOMOVE 확장 선례 조사

- 작성일: 2026-11-25
- 목적: "이사로 진입 → 주거 생활 전반(입주 직후 시공·가구가전 구매, 거주 중 교체·보관·정기 청소, 다음 이사)으로 확장" 경로가 실제로 성립한 선례·실패한 선례 확인
- 범위: 오늘의집(버킷플레이스), 해외(Porch·Updater·Zillow·Angi·Thumbtack·Frontdoor·SUUMO·ietty), 국내(직방·다방·호갱노노·KB부동산·아파트아이·집닥·한샘·현대리바트·LX지인·홈닉·헬로입주)
- 방법: DART 감사보고서 원문(버킷플레이스·직방), 웹 검색·웹 문서 조회. 브라우저 창 미사용
- 근거 성격 표기: 공시 / 공식 자료 / 언론 보도 / 업체 자료 / 제3자 자료 / 당사 추정
- 구분: 1~3장은 외부 리서치 결과. 4장 결론과 ROOMOVE 시사점은 당사 해석이며 사용자 확정 판단 아님
- 보고서 반영 전 설명·합의 필요(사내벤처 규칙)

---

## 요약

1. **이사 연결만으로 큰 사업이 된 사례 없음.** 미국 Updater는 연 236만 건 이사를 처리하고도 분기 현금수입이 약 169만 달러(2017년 4분기) 수준, 2022년 인원 감축. Porch도 이사 부문은 건당 매출 약 215~311달러로 작고 이익을 내는 곳은 보험
2. **확장이 성립한 곳은 "이사·주택 구입 시점을 싼 고객 획득 통로로 쓰고, 매년 다시 돈을 내는 상품으로 넘긴" 경우.** Frontdoor(주택 보증, 갱신 매출이 첫해 매출의 약 5배, 유지율 약 79%), Porch(보험 매출이 연결 매출의 과반)
3. **입구는 대부분 업무용 도구·기업 경로(B2B)로 확보.** Porch는 주택 검사관 소프트웨어(미국 주택 검사의 약 절반), Updater는 중개사·임대관리사 초대, Frontdoor는 신축 건설사(2-10 인수). 국내 홈닉도 건설사 입주민 앱
4. **집값·공사·손해 위험을 직접 진 확장은 크게 잃음.** Zillow 집 직접 매입(2021년 재고 감액 4억 790만 달러, 인력 약 25% 감축), Porch 보험사 직접 운영(2023년 순손실 1억 3,390만 달러), 직방 스마트홈·중개법인(2025년 계열사 대여금 대손 470.7억 원)
5. **오늘의집은 커머스 → 시공 중개 → 이사 견적 → 직영 부분시공(2025년 자회사) → 무빙패스(2026-10)로 같은 목표에 접근 중.** 다만 무빙패스는 견적 신청 시 쇼핑 쿠폰을 주는 멤버십이고, 외부 구매처·외부 업체 사이 일정 조율 기능은 확인 못 함
6. **ROOMOVE 자리(외부 업체·외부 구매처 사이 일정 조율) 근거는 "빈 자리는 있다"까지.** 그 자리만으로 돈이 되는 근거는 약하고(Updater·Hello Alfred 선례), 반복 매출 상품과 입주일을 미리 아는 경로 확보가 함께 필요

### 1-4. 오늘의집이 아직 다루지 않거나 불만이 많은 문제

- **입점 판매자 배송 관리**
  - 입점 판매자 품절·취소를 알려 주지 않는다는 이용자 글(제3자 자료, [클리앙 2026-04-07](https://www.clien.net/service/board/park/19174169))
  - 같이 산 상품이 따로 도착(테이블 3일, 의자 2~4주), 회사도 가구 배송 경험 미흡 인정(언론 보도, 바이라인네트워크 2021-06-29). 자체 배송은 직매입 상품·수도권 직접 배차에 한정
- **시공 지연·업체 문제**
  - 무면허 업체 3,000만 원 공사 지연·연락 두절·하자, 중재 무산 사례(언론 보도, [비즈한국 2022-12-23](https://bizhankook.com/articles/24944.html))
  - 시공책임보장은 보장 대상 업체에만 적용(언론 보도, 이코노미스트 2023-06)
  - 2024-12-12 공정위, 오늘의집 등 6개 인테리어 플랫폼 불공정 약관 84개 조항 시정("통신판매중개자라 책임 없음" 일괄 면책 수정)(공식 자료 인용 언론 보도, [디지털데일리](https://www.ddaily.co.kr/page/view/2024121214163632837))
- **업계 전체 불만 숫자(오늘의집만 따로 집계한 수치는 확인 못 함)**
  - 인테리어 플랫폼 상담·피해구제: 2019년 13건 → 2022년 60건(소비자원 자료 인용 언론 보도)
  - 온라인 가구 배송 피해 2025년 239건 중 배송 지연·미배송 26.4%(63건)(공식 자료 인용 언론 보도, [경향신문 2026-06-16](https://www.khan.co.kr/article/202606161513011/)). 2021~2025 누적은 보도마다 1,052건·152건으로 달라 원자료 확인 필요

### 4-2. 이사 진입 → 주거 생활 확장이 성립한 조건

1. **매년 다시 돈을 내는 상품 보유**: 보험(Porch), 주택 보증(Frontdoor). 이사 자체는 반복이 약함
2. **싼 입구를 업무 도구·기업 경로로 확보**: 검사관 소프트웨어, 중개사 초대, 신축 건설사, 건설사 입주민 앱
3. **위험은 남에게 넘기고 수수료로 수익**: Porch 상호보험 전환, Zillow 연결·대출
4. **입주일·평면을 미리 아는 위치**: 홈닉·Frontdoor 2-10처럼 일정 정보를 가진 쪽이 묶음을 주도

### 4-3. 실패한 조건

1. **1회성 연결 수수료만**: Updater, 다방, Porch 이사 부문
2. **위험·고정비 직접 부담**: Zillow 집 매입, Porch 보험 직접 운영, 직방 스마트홈·중개법인, 한샘 대형 전시장
3. **기존 사업자와 정면 충돌**: 직방 중개 수수료 구조에 공인중개사협회 반발, 오늘의집 직영 시공과 입점 업체 이해충돌
4. **주택 거래·입주 물량에 수요가 묶임**: 한샘·현대리바트

### 4-4. ROOMOVE 자리(외부 업체·외부 구매처 사이 일정 조율)

**성립할 근거**
- 오늘의집은 자기 판매 상품·자기 시공에만 일정 관리 제공. 무빙패스는 견적 신청 쿠폰이며 외부 구매처 물건·외부 업체 일정 조율 기능 확인 못 함 → 빈 자리 존재
- 오늘의집 직영 부분시공에 "본사 전담 매니저가 일정 관리"를 넣은 것 자체가 일정 관리에 고객 가치가 있다는 신호(언론 보도, 지디넷 2026-07-03). 계약액 전년 대비 약 3배
- 업계 불만이 배송 지연·묶음 배송 분리·시공 지연에 몰림(소비자원 자료 인용 보도, 이용자 글). 다만 일정 꼬임만 떼어 낸 숫자는 확인 못 함
- 구매처를 묻지 않는 중립 위치는 오늘의집·한샘처럼 자기 상품을 파는 쪽이 취하기 어려운 위치(당사 해석)

**반대 근거**
- 일정 조율 자체로는 건당 수익이 작을 위험: Updater(건당 몇 달러, 당사 추정), Porch 이사 부문 축소, 앞선 조사의 Hello Alfred(전담 인력이 확장 벽)
- 사람이 조율하면 인건비가 늘어남(Updater 2018 손실 원인 인건비, 경쟁사 조사 2026-11-25 참고)
- 반복 매출 상품이 아직 없음. 확장 선례는 모두 보험·보증 같은 연 갱신 상품으로 수익화
- 입주일·평면을 먼저 아는 쪽(홈닉·헬로입주·아파트아이·건설사 앱)이 이미 묶음을 키우는 중. 이들이 조율 기능을 붙이면 따라잡힐 위험
- 오늘의집은 현금성자산 약 2,429억 원, 차입금 없음(공시) → 외부 업체 조율로 범위를 넓힐 자금 여력 있음
- 조율 책임 범위가 넓으면 단순 중개보다 법적 책임 노출 큼(공정위 2024-12 약관 시정, 수익모델·규제 검증 2026-11-25 참고)

**검증이 필요한 것**
- 오늘의집 앱 이사 탭·무빙패스에서 외부 구매 물건 일정 등록 기능 유무(앱 직접 확인)
- 고객이 일정 조율에 따로 돈을 낼지, 업체가 낼지(고객·업체 인터뷰)
- 입주 후 반복 상품 후보(정기 청소·보관·가전 보증)의 재구매율
- 건설사 입주민 앱·관리 앱과 제휴 시 입주일 정보 확보 가능성

### 4-5. ROOMOVE 시사점 (당사 해석, 사용자 확정 아님)

1. **조율은 입구, 수익은 반복 상품.** 일정 조율은 고객을 붙잡는 장치로 두고, 입주 후 매년 다시 돈을 내는 상품(정기 청소·보관·가전 보증 등)을 확장의 목표로 설계
2. **입구는 B2B 경로로.** 이사업체·중개사·건설사·관리 앱 등 이사 일정을 미리 아는 쪽과 제휴해 고객 획득 비용 절감
3. **직접 시공·재고 위험은 피함.** 오늘의집 직영화·직방 스마트홈·Zillow 집 매입 선례상, 확장 시 업체 연결과 수수료 구조 유지
4. **"구매처를 묻지 않는 중립"을 차별점으로 명시.** 오늘의집이 자기 상품·자기 시공 중심인 지금이 빈 자리. 다만 오늘의집·홈닉이 기능을 붙일 수 있어 빠른 검증 필요
5. **조율 인건비 상한 설정.** 이사매니저 1인당 처리 건수와 건당 수익을 먼저 재고, 사람 손이 가는 부분의 자동화 범위 결정
