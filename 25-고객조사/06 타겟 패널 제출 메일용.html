타깃 패널 컨셉 테스트 제출 (그날의 류)

몸으로 해 오던 셀프 지압을, 앱이 자리를 짚고 기기가 대신 눌러 주는 루틴으로 바꾸고 싶어 하는가. 가설 조합은 잠정(팀 확정 전).

1. 알고 싶은 항목 (To-Know list)

#알고 싶은 것활용처가설
★1지금 다리·발이 무거운 날 하는 방법과 비교해, 앱이 발목 혈자리를 짚고 기기가 대신 눌러 주는 이 루틴을 더 써 보고 싶은가? 그렇게 답한 이유는?한 줄 약속("몸으로 해 오던 번거로운 셀프케어")을 그대로 둘지누가 다리·발이 무거운 날 손이나 도구로 직접 눌러 온 사람이
무엇을 앱이 자리를 짚고 기기가 대신 눌러 주는 발목 루틴을
무엇보다 더 손으로 직접 누르거나 넓게 주무르는 마사지기보다 더 써 보고 싶어 할 것
왜 지금은 자리를 알려 주는 것도 영상뿐이고, 한 지점을 계속 눌러 주는 것도 내 손뿐이어서
틀리면 '번거로움을 덜어 준다'를 내리고, 마사지기와 다른 점(한 지점·일정한 힘)이나 쉬는 시간의 경험을 첫 줄로 올린다
★2손이나 도구로 혈자리·다리를 눌러 본 적이 있나? 그만뒀거나 가끔만 한다면 가장 큰 이유는? — 맞는 자리인지 몰라서 / 허리를 숙여 손으로 누르기 힘들어서 / 오래 누르면 손이 아파서 / 일하거나 다른 일을 하면서 못 해서 / 할 때마다 영상을 다시 찾아야 해서 / 시간이 없어서 / 효과를 못 느껴서 / 지금도 꾸준히 한다앱(자리 안내)과 기기(대신 누르기) 중 무엇을 앞세울지, 효과 확인(체험·환불)을 먼저 할지누가 셀프 지압을 해 본 사람이
무엇을 그만둔 이유로
무엇보다 더 '효과를 못 느껴서'보다 '자리를 몰라서·손으로 계속 누르기 힘들어서·일하면서 못 해서'를 더 많이 꼽을 것
왜 지압은 같은 자리를 같은 힘으로 오래 눌러야 하는데, 발목처럼 허리를 숙여야 하는 자리는 손으로 이어 가기 어려워서
틀리면 '힘들이지 않고, 닿지 않던 곳까지'를 내리고 체험·환불로 효과 의심부터 푼다
★3셀프 지압 경험이 있는 사람과 없는 사람 중 누가 이 루틴을 더 써 보고 싶어 하나? 주로 서서 일하는 사람과 앉아서 일하는 사람 중에서는? 그 이유는?첫 고객 정의, 첫 장면(퇴근 후 / 일하는 중)누가 셀프 지압을 해 본 사람이
무엇을 이 루틴을
무엇보다 더 해 본 적 없는 사람보다 더 써 보고 싶어 할 것
왜 이미 하던 관리를 대신해 주는 것이라 쓰임을 바로 이해해서
틀리면 경험 없는 쪽 반응이 같거나 크면 첫 고객을 넓히고 메시지를 '처음 시작하는 쉼 루틴'으로 바꾼다
4앱만 먼저 무료로 써 볼 수 있다면? — 앱만 먼저 써 보고 기기를 고민하겠다 / 바로 기기까지 사겠다 / 앱만 쓰고 기기는 안 살 것 같다 / 둘 다 관심 없다앱 무료 → 기기 구매 흐름을 첫 판매 경로로 둘지셀프 지압 경험자는 '앱만 먼저'를 가장 많이 고를 것
5이 루틴을 언제 쓰겠나? (모두) — 퇴근 후 / 앉아서 일하는 중 / 잠들기 전 / 오래 걷거나 서 있은 날 / 운동 후 / 몇 번 쓰다 말 것 같다첫 사용 장면, 알림 시점'퇴근 후'와 '잠들기 전'이 '일하는 중'보다 많을 것
6장점 중 가장 중요한 것 1~3순위 — 앱이 자리를 짚어 줌 / 기기가 대신 눌러 줌 / 두 손이 자유로움 / 일정한 힘으로 눌러 줌 / 내 자리와 방법이 앱에 저장됨 / 셀프케어 기록 / 황토볼 패치 / 앱은 무료상세페이지 첫 장점, 앱과 기기 중 무엇이 구매 이유인지경험자는 '앱이 자리를 짚어 줌'과 '기기가 대신 눌러 줌'을 함께 상위에 꼽을 것
7걱정 중 가장 망설여지는 것 1~3순위 — 효과가 있을지 모르겠음 / 가격 / 충전·착용이 번거로움 / 카메라로 자리를 제대로 짚을지 / 패치를 계속 사야 할 것 같음 / 안전 걱정 / 마사지기와 차이를 모르겠음. 무엇이 있으면 안심하겠나? — 무료 체험 / 환불 / 사용 후기 / 전문가 설명먼저 풀 걱정, 체험·환불 장치'효과가 있을지 모르겠음'이 가격보다 클 것
8이 루틴을 보면 어떤 것과 비교하게 되나? — 손으로 직접 누르기 / 영상 따라 하기 / 수동 지압·괄사 도구 / 마사지볼·폼롤러 / 공기압·전동 다리 마사지기 / 안마의자 / 마사지샵·한의원 / 비교할 것이 없음가격 기준점, 판매 카테고리공기압·전동 다리 마사지기와 비교할 것
9기기 + 패치 1팩 99,000원이면 어떤가? — 살 만하다 / 비싸지만 고민해 보겠다 / 비싸다. 비싸다면 얼마면 사겠나? — 3만 원대 / 5만 원대 / 7만 원대가격 설득 문구, 가격 시험안마사지기 경험자는 '살 만하다', 손 지압만 해 본 사람은 '비싸다'가 많을 것
10교체용 패치(8,000원)는 어떻게 사겠나? — 기기만 쓰고 패치는 안 산다 / 필요할 때만 / 패치 교체 알림을 받으면 산다 / 정기 배송패치 판매 방식, 교체 알림
11이 루틴에서 무엇을 기대하나? (모두) — 무거운 다리를 시원하게 / 붓기를 덜고 싶어서 / 잠들기 전 쉬는 시간 / 피로를 풀고 싶어서 / 통증 치료효능 오인 위험 확인("의료기기가 아닌 웰니스 생활용품" 문구가 통하는지)'통증 치료'를 고르는 사람은 적을 것. 많으면 효능 오인 위험으로 보고 문구를 고친다
12같은 앱·같은 방식으로 다음 루틴이 나온다면 관심이 있나? — 일하는 중 어깨·목 / 잠들기 전 쉼 / 부모님 선물 / 성장기 아이 잠들기 전 / 관심 없음확장 순서(보드 하단 ①~④)'일하는 중 어깨·목'이 가장 많을 것

2. 타깃 조건 (3개)

  1. 만 20~49세 성인(성별 무관). 임신 중이거나 임신 가능성이 있지 않고, 발목 부상·당뇨 등 발의 감각 이상이 없다
  2. 일주일에 3일 이상, 하루 대부분을 서 있거나 앉아서 일한다
  3. 최근 1개월 안에 다리나 발이 무겁거나 붓는다고 느낀 날이 여러 번 있다

분류 문항

  • C1 다리·발이 무거운 날 해 본 방법을 모두 고르세요. — 그냥 쉬거나 참기 / 손으로 직접 누르기 / 영상 보고 따라 하기 / 지압·괄사 도구 / 마사지볼·폼롤러 / 공기압·전동 다리 마사지기 / 안마의자 / 찜질·족욕·반신욕 / 압박 스타킹 / 스트레칭·운동 / 마사지샵·한의원·물리치료 / 파스·진통제 → 쿼터: '손으로 직접 누르기', '영상 보고 따라 하기', '지압·괄사 도구' 중 하나 이상이면 '셀프 지압 경험 있음'
  • C2 일할 때 주로 어떻게 있나? — 주로 서서 / 주로 앉아서 / 반반 → 쿼터 (반반은 더 긴 쪽으로 다시 물음)
  • C3 성별, 나이(20대 / 30대 / 40대) → 결과에서 나눠 보기

3. 경쟁 서비스 / 꼭 확인하고 싶은 문항

보기에 꼭 넣을 경쟁·대체 방법

  1. 그냥 쉬거나 참는다
  2. 손으로 직접 누른다
  3. 영상을 보고 지압·마사지를 따라 한다
  4. 지압·괄사 도구를 쓴다
  5. 마사지볼·폼롤러를 쓴다
  6. 공기압·전동 다리 마사지기를 쓴다
  7. 안마의자를 쓴다
  8. 찜질·족욕·반신욕을 한다
  9. 압박 스타킹을 신는다
  10. 스트레칭·운동을 한다
  11. 마사지샵·한의원·물리치료를 받는다
  12. 파스나 진통제를 쓴다

꼭 확인하고 싶은 문항 (결과에서 먼저 볼 ★ 3줄)

  1. ★1: 이 루틴을 '지금 방법보다 더 써 보고 싶다'가 높은가. 특히 손으로 직접 누르거나 영상을 따라 해 온 사람에게서 높은가
  2. ★2: 그만둔 이유에서 '자리를 몰라서·손으로 계속 누르기 힘들어서·일하면서 못 해서'가 '효과를 못 느껴서'보다 많은가
  3. ★3: 셀프 지압 경험 '있음' 집단이 '없음' 집단보다 더 써 보고 싶어 하는가. 서서 일하는 집단과 앉아서 일하는 집단 중 어디가 더 높은가

보여 줄 가격: 기기 + 패치 1팩 99,000원 / 교체용 패치 1팩 8,000원 / 웰니스 앱 무료(앱만 먼저 써 볼 수 있음)
