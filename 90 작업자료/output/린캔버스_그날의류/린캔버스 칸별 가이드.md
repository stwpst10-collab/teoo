# 린캔버스 칸별 가이드 (예시 장표 옮김, 2026-11-05)

## 왜 린 캔버스인가요?

수십 장의 사업계획서 대신, 사업의 성패를 가르는 9가지 핵심 질문에만 답하는 1페이지 도구입니다.

## 작성 순서 — 이 흐름대로 채우면 논리가 이어집니다

② 고객 → ① 문제 → ④ 해결책 → ③ 가치 제안 → ⑥ 수익 → ⑧ 채널 → ⑨ 핵심 지표 → ⑦ 비용 → ⑤ 경쟁 우위

## 칸별 가이드 — 정의 · 함정 체크 · 잘 쓴 예시 ('직장인 점심 추천 앱' 가상 예시)

| 칸 | 정의 | 함정 체크 | 잘 쓴 예시 |
|---|---|---|---|
| ① 문제 | 해결할 핵심 불편 (최대 3개) | '불편하다'에서 멈추지 말고 손실(시간·비용)까지 | 메뉴 결정에 매일 15분 — 월 5시간 손실 + 결정 스트레스 |
| ② 고객 | 최우선 타깃 고객군 | "20~30대 직장인"처럼 넓으면 실패 — 상황·역할까지 좁히기 | 점심시간이 50분뿐인 판교 IT기업 3년차 사무직 |
| ③ 가치 제안 | 대안 대비 "왜 하필 이것"을 한 문장에 | 일반적 미사여구는 차별점이 아님 | "리뷰 검색 없이, 열면 3초 만에 오늘 점심 확정" |
| ④ 해결책 | 문제와 1:1로 대응하는 핵심 기능 | 매핑 안 되는 기능은 아직 필요 없는 기능 | 취향·어제 메뉴 학습 → 반경 300m 안에서 3곳만 추천 |
| ⑤ 경쟁 우위 | 남이 못 따라 하는 진짜 해자 | 돈으로 살 수 있으면 우위가 아님 — 없으면 "아직 없음"이 정직한 답 | 사내 식대 결제 데이터 제휴 독점 (없다면 "아직 없음") |
| ⑥ 수익 | 수익 모델 + 초기 가격 가설 | "일단 모으고 나중에 과금"은 모델이 아님 | 월 1,900원 구독 — "커피 반 잔 값" 가격 프레임 |
| ⑦ 비용 | 주요 비용 항목과 규모 | 수익과 대조해 팔수록 남는 구조인지 | 서버·데이터 월 200만원 → 구독 1,000명이 손익분기 |
| ⑧ 채널 | 고객에게 실제로 닿는 경로 | 막연한 'SNS 바이럴' 금지 — 직접 도달 경로부터 | 판교 입주사 3곳 사내 게시판 제휴로 첫 500명 |
| ⑨ 핵심 지표 | 성장을 증명할 행동·전환 지표 | 누적 방문 수 같은 허영 지표 배제 | 주간 추천 수락률 40% · 4주 재사용률 50% |
