# 10-아이템탐색

그날의 류 다음 아이템을 찾는 곳이다(2026-11-14 시작). 아이디어 하나당 노트 하나를 둔다.

| 파일 | 역할 |
|---|---|
| [[새 아이템 검토 기준]] | 팀원 기준: 충족 조건 6개, 타깃 채점 120점(CJ 연계 시 140점), 입력·출력 양식, 지금까지 나온 후보 표 |
| [[해커톤 피드백 반영 점검표]] | 그날의 류가 해커톤·멘토링에서 지적받은 점을 새 아이템이 피했는지 보는 체크리스트 |
| `근거/` | 출처 노트. 원문 파일은 `근거/첨부/` |
| `산출물/` | 후보별 장표 |

## 후보 상태

| 후보 | 낸 사람 | status | 노트 |
|---|---|---|---|
| 무독성 해충 관리 시스템 | 팀원 | 아이디어 | [[무독성 해충 관리 시스템]] |
| 쉼표 폭염 휴식 기록 시스템 | 사용자 요청, Claude 작성 | 아이디어 | [[쉼표 폭염 휴식 기록 시스템]] |

팀원 순위표의 나머지 후보(삼킴장애 가족, 입덧, 영유아 아토피, 노견, 등 가려움 등 18개)는 [[새 아이템 검토 기준]]의 후보 표와 원문 아카이브 461~524줄에 있다.

status는 아이디어 → 검증 중 → 채택 / 보류 / 폐기 순서로 바꾸고, 보류·폐기도 이유와 날짜를 남긴 채 노트를 지우지 않는다.
