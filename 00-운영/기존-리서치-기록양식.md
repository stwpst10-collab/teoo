# 리서치 기록 양식

이 문서는 이관 전 양식을 보존한 기록이다. 신규 제출은 [공동 작업 리서치 양식](양식/리서치.md)을 사용한다.

새 리서치 기록에 아래 항목을 복사한다. 문서마다 질문 하나를 우선 다룬다.

- 질문 ID / 질문:
- 조사일 / 조사자:
- 결론: 확인 / 반박 / 판단 유보
- 주장: 무엇이 사실이라고 말하는가?
- 근거: 원문 파일 또는 URL, 문서 날짜, 페이지·슬라이드·발언 위치
- 근거 성격: 사용자 결정 / 업체 설명 / 실측 / 논문 / 공식 규정 / 추정
- 적용 범위: 수동 목업 또는 후속 완성제품, 대상·조건·수량·단위
- 반대 근거 / 한계:
- 변경이 필요한 가정 또는 결정:
- 다음 행동 / 담당 / 기한:

규정·특허·의학적 효과 관련 결론은 업체 설명만으로 확정하지 않는다. 조사 결과가 없으면 미확인으로 남긴다.
