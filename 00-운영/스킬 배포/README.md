# 스킬 배포

팀원이 같이 쓰는 Claude 스킬을 여기서 나눠 준다.

| 스킬 | 하는 일 | 파일 |
|---|---|---|
| `/idea-criteria` | 팀원의 새 아이템 발굴 기준과 아이템 정리 템플릿 6조건을 불러온다. 아이디어를 함께 주면 기준마다 맞는지 표로 대 본다 | [idea-criteria.zip](idea-criteria.zip) |

## 쓰는 법

- **claude.ai(웹·앱)**: zip을 내려받아 claude.ai 설정 → 기능 → 스킬에서 업로드한다. 그 뒤 대화창에 `/idea-criteria`를 입력한다.
- **Claude Code**: 이 저장소를 받고 `venture` 폴더에서 Claude Code를 연다. `.claude/skills/idea-criteria/`가 자동으로 잡힌다. 상위 폴더에서 열면 명령이 인식되지 않는다.

스킬을 고치면 `.claude/skills/idea-criteria/`와 이 zip을 함께 바꾼다.
