# 보고서 워드 작업 기준

그날의 류 보고서(최종 보고서·투자 보고서·해커톤 보고서)를 워드로 만들고 고칠 때 매번 따르는 기준이다. 사용자가 한 번 지적한 것은 여기에 적고, 다음 판부터 다시 말하지 않아도 되게 한다. 새 지적이 나오면 해당 절에 한 줄 추가하고 날짜를 붙인다. 세션 역할·커밋 규칙은 [[AI 세션 운영]]을 따른다.

## 1. 구성과 번호

- 장 순서는 최종 보고서 최신판을 따른다: 1. Investment Highlights → 2. 시장 분석 → 3. 사업 분석 → 4. 경쟁 분석 → 5. 재무계획 → 6. 매출추정 → 7. 리스크 및 대응 → 8. 결론.
- 표지 다음 쪽에 자동 목차(제목 1·2 수준)를 둔다. 장마다 새 쪽에서 시작한다.
- 장 제목은 "N. 이름"(제목 1), 절 제목은 "N.M  결론형 문장"(제목 2).
- **장 아래 절이 하나뿐이면 절 번호를 붙이지 않는다**(1.1만 있고 1.2가 없으면 번호 없이 제목만). 2026-11-07 지적.
- 절을 옮기거나 추가한 뒤에는 `python tools/pitch/live.py renumber`로 번호와 목차를 다시 맞춘다.
- 보고서에 넣지 않는 것: 추진조건·추진 현황·팀 구성·발표 전 과제·개정 이력, IP 소유권 논의. 이런 정보는 발표 자료용이다.

## 2. 문체와 표현

- 국내 증권사 리포트·상장사 IR 자료 말투로 쓴다. 소제목은 결론형 명사구, 본문은 "~로 판단된다 / ~할 전망이다 / ~에 불과하다".
- 브랜드 한 줄·소제목·문제·해법 문구는 최신 린캔버스와 팀원 발표 장표의 표현을 그대로 쓴다. 예: "두 손을 자유롭게!", "PMS 일주일, 아무도 맡지 않은 시장", "거의 모두가 겪지만, 거의 아무도 관리받지 않는다", "기기만으로도 충분해요. 패치는 선택". 팀 문구가 없는 장은 꾸미지 않은 평범한 제목을 쓴다.
- 직역한 조어를 쓰지 않는다: 넓은 불편→대규모 미충족 수요, 빈칸·칸→공백·카테고리 부재, 사다리→단계별 구분, 갈래→분야, 출렁임→변동성, 서랍행→사용 중단, 우리 길 아님→사업 범위 밖, 출발점→착안 배경.
- 영어 약어 대신 한글로 쓴다(TAM→전체 시장, CAC→고객 획득 비용 등). 고유명사는 예외.
- 효능·치료로 읽히는 표현을 쓰지 않는다("PMS 치료·완화", "부작용 우려가 있는 호르몬제" 등).

## 3. 숫자와 근거

- 숫자는 최신 보고서·검증 값을 1순위로 쓰고, 출처가 없으면 지어내지 않고 "근거 없음"이라고 쓴다.
- 출처만이 아니라 왜 그 값인지(어떤 분포의 어느 지점인지)를 붙인다. 가정값은 "당사 추정"이라고 밝힌다.
- **같은 대상은 문서 전체에서 같은 숫자를 쓴다.** 표지·본문·차트·표의 연령 범위와 인원이 서로 달라지지 않게 한다. 범위를 바꾸면 관련 문장·차트를 함께 바꾸거나 사용자에게 남은 곳을 알린다. 2026-11-07(표지 15~39세 317만~337만명 vs 본문 25~39세 228만~239만명).
- 연령 범위를 바꾸면 원표(주민등록인구 1세별·질병관리청 연령별 비율)로 다시 계산한다. 조사 연령대와 다르게 적용한 부분은 각주에 밝힌다.

## 4. 출처 표기

- 본문에 A/B/C/D 등급을 쓰지 않는다. 투자·해커톤 보고서는 출처를 **각 쪽 아래 워드 각주**로 단다. 맨 끝에 번호 목록으로 모으지 않는다. 2026-11-07 지적.
- 같은 출처가 여러 쪽에 나오면 쪽마다 각주를 단다. 출처 칸에 "같은 노트"·"같은 보도" 같은 지시어를 쓰지 않는다.
- 차트·표 아래에는 "자료: 기관명(시점), 그날의 류 추정" 한 줄을 둔다. 차트 그림 안에는 각주 번호를 넣지 않는다.
- 본문에 `[n]`을 쓰면 `python tools/pitch/live.py footnotes`로 각주로 바꾼다(출처 목록은 `tools/pitch/sources.json`).

## 5. 차트와 표

- 색은 검증 팔레트의 파랑(#2a78d6)·주황(#eb6834)만 쓴다. 범례가 2개 이상이면 범례를 두고, 값은 막대 끝에 직접 적는다. 축 두 개짜리 차트는 만들지 않는다.
- 엑셀 시뮬레이션에서 나오는 숫자는 손으로 옮기지 않고 연동 차트·표로 넣는다(`80-산출물/시뮬레이션모델링` 최신 버전 자동 사용). 엑셀을 고친 뒤 `python tools/pitch/live.py sync`.
- 표는 쪽 사이에서 갈라지지 않게 한다(행 나눔 금지, 마지막 행 전까지 다음 단락과 함께).

## 6. 워드 서식

- 글꼴은 맑은 고딕. 본문 10.5pt, 절 제목 16pt, 장 제목 20pt, 각주 8pt.
- 제목·라벨 문단에는 "다음 문단과 함께"를 걸어 쪽 끝에 제목만 남지 않게 한다. 화면의 검은 네모는 이 설정의 편집 기호이며 인쇄되지 않는다(끄기: 파일 → 옵션 → 표시 → 단락 기호 해제).

## 7. 파일과 공동 작업

- 로컬은 `venture` 폴더 하나, 브랜치는 `main` 하나. 작업할 때마다 커밋하고 바로 main에 push한다. docx·pdf·xlsx도 빠짐없이 올린다.
- 사용자가 워드를 열어 둔 채 같이 고친다. 제 작업은 열린 창에 바로 넣고(`tools/pitch/live.py`), 작업마다 저장한다. 작업 하나는 워드 Ctrl+Z 한 번으로 되돌릴 수 있게 묶는다.
- 문서는 한 파일만 고친다. 같은 문서를 다른 폴더에 복사해 따로 고치지 않는다.

## 도구 명령 (`tools/pitch/live.py`)

| 명령 | 하는 일 |
|---|---|
| `open` | 문서를 워드로 연다 |
| `add <차트ID> --after "문구"` | 문구가 있는 문단 뒤에 차트를 넣는다 |
| `sync` | 엑셀 최신본으로 연동 차트·표·출처 문구를 갱신한다 |
| `footnotes` | 본문 `[n]`을 쪽 아래 각주로 바꾼다 |
| `renumber` | 절 번호를 다시 매기고(절 하나면 번호 없음) 목차를 갱신한다 |
| `save` | 저장만 한다 |
